FREEDAM is a non-partisan, open-source DAO building permissionless infrastructure for civic governance. We deploy blockchain primitives — soulbound membership credentials, quadratic voting, and transparent treasuries — to give democratic participation back to individuals rather than institutions.

This is not a DeFi protocol. This is a movement.

What We're Building

🆔

Soulbound Membership

FRDM-ID is a non-transferable, free-to-mint identity credential. One person, one membership. No whales, no sybils, no gatekeepers.

🗳️

Quadratic Voting

Power balances toward the many, not the few. Votes reflect conviction, not capital.

📜

Transparent Proposals

Every proposal, every vote, every treasury move — on-chain, verifiable, and permanent.

🔓

Open Source Everything

All code is MIT licensed. All governance is CC BY 4.0. Fork it, audit it, improve it. No permission needed.

Token Model

Membership

FRDM-ID

ERC-1155 soulbound credential. Non-transferable, free to mint. Grants proposal and voting rights.

Governance

FRDM

ERC-20 governance token earned through participation, not sold. Powers quadratic voting weight.
